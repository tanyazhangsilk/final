# E-Charge 聚合充电平台 - 启动指南

## 环境要求

- Python 3.10+
- MySQL 5.7+ / 8.0
- Node.js 18+
- 微信开发者工具

## 1. 数据库配置

### 创建 MySQL 数据库

```sql
CREATE DATABASE IF NOT EXISTS e_charge CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 配置数据库连接

编辑 `backend/.env` 或项目根目录 `.env`：

```env
MYSQL_USER=root
MYSQL_PASSWORD=your_password
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_DB=e_charge
```

## 2. 后端启动

```bash
# 进入后端目录
cd D:\AAA-Echarge\echarge-master

# 安装依赖
pip install -r requirements.txt

# 初始化数据库表
python scripts/patch_demo_schema.py

# 初始化演示数据（运营商、用户、电站、订单、优惠券）
python scripts\init_demo_data.py

# 添加更多充电站/电桩数据（15+站点，覆盖成都、深圳、广州、杭州、上海、北京）
python scripts\seed_more_stations.py

# 启动后端服务（默认 8000 端口）
python main.py
```

启动后访问 http://localhost:8001/docs 可查看 API 文档。

### 管理端 Vue 前端

```bash
cd frontend
npm install
npm run dev
```

访问 http://localhost:5173

- **管理员登录**: `admin@echarge.com` / `admin123`
- **运营商登录**: `operator@echarge.com` / `operator123`

## 4. 功能验证流程

### 小程序端功能

1. **登录** — 使用 `13800138000` / `123456` 登录
2. **查找电站** — 查看附近充电站列表和详情
3. **扫码充电** — 输入电桩 SN 编码开始充电
4. **充电监控** — 实时查看充电进度（电量、费用、时长）
5. **结束充电** — 手动结束充电并扣费
6. **历史订单** — 查看充电记录
7. **钱包** — 查看余额、充值、交易记录
8. **发票** — 申请电子发票
9. **优惠券** — 领取可用优惠券

### 管理端功能

1. **实时订单** — 查看当前充电中的会话
2. **历史订单** — 查看已完成订单详情
3. **电站管理** — 审核、配置电站和电桩
4. **计费模板** — 创建和管理电价模板
5. **财务管理** — 结算清分、发票处理
6. **优惠券管理** — 创建和投放优惠券
7. **用户管理** — 管理平台用户

## 6. 充电模拟 API

充电监控页面使用轮询获取实时充电状态。后端会模拟充电进度：

- 电量逐步上升（15%-98%）
- 费用按实际阶梯电价计算
- 充电功率随 SOC 升高而递减

API 端点：`GET /api/v1/charging/status/{order_id}`
